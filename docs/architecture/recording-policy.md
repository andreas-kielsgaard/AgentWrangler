# Recording policy

Architecture records distinguish four kinds of material:

- **Confirmed** — explicitly selected or named by the user.
- **Working inference** — a consequence or interpretation inferred from confirmed direction.
- **Proposal** — an option suggested for consideration but not accepted.
- **Open** — an unresolved design question.

Names use the same distinction. Repeated use of a proposed term does not make it confirmed.

When a working inference is necessary, record the confirmed direction it follows from. Do not promote an inference or proposal to confirmed without explicit user confirmation.
